# Binary Digits

**This file doesn't look like much... just a bunch of 1s and 0s. But maybe it's not just random noise. Can you recover anything meaningful from this?**

Se nos proporciona un archivo con un montón de binarios. Para resolver el problema nos dirigimos a la herramienta cyberchef y subimos el archivo, posteriormente decodificamos el binario y nos sale lo siguiente un montón de texto raro lo que significa que falta un paso, utilizando el detector automatico de cyberchef este basicamente nos dice que falta la opción de render image, utilizando la opción de from binary y render imagen obtenemos una imagen que es la siguiente:
